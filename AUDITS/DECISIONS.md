## Исходные решения (зафиксированы по PROJECT_HANDOFF.md §15, ревизия 2026-08-05)

> Эти решения уже приняты и действуют в проекте. Перенесены сюда как отправная точка журнала.
> Полные обоснования — в `PROJECT_HANDOFF.md`, раздел 15.

### [ADR-001] Отдельный HTTP endpoint `POST /api/bot/upload` для бота

- **Дата:** 2026-08-05 (перенос)
- **Решение:** Telegram Admin Bot публикует релизы напрямую через HTTP API сайта.
- **Причина:** Studio использует Server Actions + presigned URL — недоступно внешнему Node.js процессу бота; нужен HTTP API с shared-secret аутентификацией.
- **Альтернативы:** переиспользовать Server Actions (невозможно вне браузера); presigned URL для бота (нужен отдельный handshake).
- **Статус:** Принято.
- **Связанные документы:** [05_API.md](05_API.md), [08_AUDIO_PIPELINE.md](08_AUDIO_PIPELINE.md), PROJECT_HANDOFF.md §11, §15.

### [ADR-002] Supabase Auth v1 (magic-link OTP) как основа сессий

- **Дата:** 2026-08-05 (перенос)
- **Решение:** Сессии Telegram-пользователей создаются через Supabase Auth magic-link OTP.
- **Причина:** Единственный путь создать сессию для Telegram-пользователя без email.
- **Альтернативы:** собственный сессионный слой без Supabase.
- **Статус:** Принято.
- **Связанные документы:** [06_AUTH.md](06_AUTH.md), PROJECT_HANDOFF.md §6.

### [ADR-003] Синтетический email `tg_<id>@forzadj.internal`

- **Дата:** 2026-08-05 (перенос)
- **Решение:** Пользователь Supabase создаётся с синтетическим email на базе Telegram ID.
- **Причина:** Telegram не предоставляет email; нужен уникальный идентификатор для Supabase Auth.
- **Альтернативы:** телефон; кастомные claims.
- **Статус:** Принято.
- **Связанные документы:** [06_AUTH.md](06_AUTH.md).

### [ADR-004] Inline job queue (без Redis)

- **Дата:** 2026-08-05 (перенос)
- **Решение:** Фоновые задачи (audio.analyze, artwork.optimize) выполняются через встроенную in-process очередь.
- **Причина:** MVP без внешних зависимостей; при масштабировании заменить на Redis/BullMQ.
- **Альтернативы:** Redis/BullMQ (отложено до роста нагрузки).
- **Статус:** Принято.
- **Связанные документы:** [08_AUDIO_PIPELINE.md](08_AUDIO_PIPELINE.md), [11_TECH_DEBT.md](11_TECH_DEBT.md).

### [ADR-005] Soft delete на всех контентных таблицах

- **Дата:** 2026-08-05 (перенос)
- **Решение:** `deletedAt`/`deletedById` + глобальный фильтр в Prisma-репозиториях.
- **Причина:** аудит изменений + возможность восстановления данных.
- **Альтернативы:** жёсткое удаление; архивные таблицы.
- **Статус:** Принято.
- **Связанные документы:** [04_DATABASE.md](04_DATABASE.md), PROJECT_HANDOFF.md §7.

### [ADR-006] UUID v7 как идентификаторы

- **Дата:** 2026-08-05 (перенос)
- **Решение:** Все `id` — UUID v7; slug — публичный идентификатор, UUID — внутренний.
- **Причина:** сортируемость, безопасность для публичных URL.
- **Альтернативы:** UUID v4 (не сортируем), auto-increment (раскрывает порядок/счётчики).
- **Статус:** Принято.
- **Связанные документы:** [04_DATABASE.md](04_DATABASE.md), [05_API.md](05_API.md).

### [ADR-007] Studio отвечает 404 вместо 401

- **Дата:** 2026-08-05 (перенос)
- **Решение:** Доступ к Studio без прав → 404.
- **Причина:** не раскрывать существование зоны гостям.
- **Альтернативы:** 401/403/redirect (раскрывают зону).
- **Статус:** Принято.
- **Связанные документы:** [02_SECURITY.md](02_SECURITY.md), [06_AUTH.md](06_AUTH.md).

### [ADR-008] WebP-варианты обложек через job queue, не per-request

- **Дата:** 2026-08-05 (перенос)
- **Решение:** Генерация WebP (1200/600/300/120) при загрузке через фоновый job `artwork.optimize`.
- **Причина:** не замедлять ответы API генерацией на лету.
- **Альтернативы:** генерация по запросу (латентность), image CDN (внешняя зависимость).
- **Статус:** Принято.
- **Связанные документы:** [07_STORAGE.md](07_STORAGE.md), [03_PERFORMANCE.md](03_PERFORMANCE.md), PROJECT_HANDOFF.md §8.

### [ADR-009] Camelot Wheel как единственная тональность в UI

- **Дата:** 2026-08-05 (перенос)
- **Решение:** Пользователю отображается только Camelot-нотация; `musicalKey` — внутреннее поле.
- **Причина:** DJ'и используют только Camelot.
- **Альтернативы:** показывать обе нотации.
- **Статус:** Принято.
- **Связанные документы:** [09_UI_UX.md](09_UI_UX.md), [08_AUDIO_PIPELINE.md](08_AUDIO_PIPELINE.md).
