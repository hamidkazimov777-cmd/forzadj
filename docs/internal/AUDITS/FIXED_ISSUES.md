## Шаблон записи

```
### [ID-XXX] Название проблемы (из раздела NN)

- **Исправлено:** YYYY-MM-DD
- **Статус в разделе на момент фикса:** 🔴 / 🟡 / 🟢 + приоритет
- **Что было:** краткое описание исходной проблемы.
- **Как исправлено:** что сделано.
- **Почему:** мотивация исправления.
- **Файлы:** затронутые файлы.
- **Подтверждение:** чем проверено (тест, коммит, ручная проверка).
```

## Исправленные проблемы

> **Как переносить фикс.** Когда проблема исправлена:
> 1. В исходном разделе её статус меняется на «Исправлено» (+ дата в истории замечания).
> 2. Запись переносится в этот файл (ниже, сверху списка).
> 3. В исходном разделе замечание остаётся со ссылкой на запись здесь (`→ FIXED_ISSUES.md#[ID]`).
> 4. Фиксируется в `CHANGELOG.md`.
